# kijnreyyca-bot.github.io

Host-level GitHub Pages configuration for every site under
`https://kijnreyyca-bot.github.io/`.

- `robots.txt` — allows traditional search engines, blocks AI training and
  answer-engine crawlers, and points to the homepage sitemap.
- `index.html` — sends the bare origin to `/homepage/`.

The project sites themselves (`homepage`, `Frame`, `eaglerMC`,
`redirect_site`, `Clickers`) live in their own repositories and are unaffected
apart from the crawl rules above.
